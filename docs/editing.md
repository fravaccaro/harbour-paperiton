# Viewing and editing

## The document view

Opening a document shows its preview along with tags, correspondent, document type, archive serial number and the OCR text the server extracted. **Open** writes the file into `~/Downloads/Paperiton` under the name the server keeps for it: pictures are shown inside Paperiton, PDFs and other files are opened with the system handler (see [Files and permissions](files)).

## Editing one document

The edit page changes title, correspondent, document type, tags, date, archive serial number and custom fields. Correspondents, types and tags are picked from what the server knows.

## Editing several documents

From the document list you can select several documents and change their tags, correspondent or document type in one step. With two or more selected, the pulley menu also offers **Download**, which writes each file into `~/Downloads/Paperiton` under the name the server keeps for it (the same archived-or-original choice a single Open would make).

## Notes

Notes on a document can be read, written and deleted from the notes page.
